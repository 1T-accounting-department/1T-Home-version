# 1T-Home-version

## Overview

**1T-Home-version** is an open-source accounting and enterprise resource planning (ERP) alternative conceptually inspired by the 1C software architecture. Designed specifically as a streamlined home and personal-use edition, the platform offers core financial tracking, inventory monitoring, and structured record management capabilities without proprietary licensing restrictions.

## Core Features

* **Open-Source Architecture**: Fully transparent codebase licensed under AGPL-3.0, allowing complete auditability, self-hosting, and community-driven modifications.
* **Home-Centric Design**: Optimized for lightweight, independent deployment to manage domestic assets, personal budgets, and small-scale ledger operations.
* **Familiar Paradigm**: Conceptual workflow and structural layout aligned with established enterprise accounting systems, facilitating intuitive adaptation for users experienced with 1C environments.
* **Web-Based Foundation**: Built using modern web technologies (HTML/JavaScript), ensuring high portability, cross-platform compatibility, and seamless execution within standard browser environments or progressive web application (PWA) containers.

## Technology Stack

* **Frontend & Core Logic**: HTML, JavaScript (Client-side execution and local state management)
